# wc-cli

CLI-утилита на Python (только стандартная библиотека) для подсчёта строк, слов и символов в файлах: печатает таблицу по каждому файлу и итоговую строку.

## Использование

```bash
uv run wc-cli file1.txt file2.txt
```

Пример вывода:

```text
lines words chars file
    3     10    50 file1.txt
    1      5    22 file2.txt
    4     15    72 total
```

## Коды возврата

- `0` — успех;
- `1` — ошибка чтения хотя бы одного файла (файл отсутствует, указан каталог, содержимое не в UTF-8);
- `2` — ошибка использования (неверные аргументы).

## Семантика подсчёта

- **lines** — число символов `\n` плюс последняя незавершённая строка;
- **words** — разбивка по любому пробельному разделителю (`str.split`);
- **chars** — количество Unicode-кодовых пунктов (не байты);
- кодировка — UTF-8 strict.
